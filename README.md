# Ritmo: app de hábitos, treino, dieta e progresso

## Arquivos
- `index.html`: o app inteiro (telas, cores e lógica).
- `manifest.json`, `sw.js`, `icons/`: deixam o app instalável no iPhone e funcionando sem internet.

## Como instalar no iPhone (depois que estiver publicado num endereço https)
1. Abra o endereço no **Safari**.
2. Toque em **Compartilhar** (quadrado com seta para cima).
3. Toque em **Adicionar à Tela de Início**.

## Onde ficam os dados
Os dados ficam só no iPhone, dentro do app. Na aba **Progresso** há o botão **Salvar cópia**: use de vez em quando e guarde o arquivo no OneDrive ou no app Arquivos. **Restaurar cópia** traz tudo de volta.

## Como editar
- Treino, refeições, metas e hábitos se editam dentro do próprio app (botões "Editar").
- Os exemplos iniciais ficam no começo do código em `index.html`, no bloco `PADRAO`.
